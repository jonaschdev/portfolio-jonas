## 📸 Como Colocar Sua Foto de Perfil

No arquivo **`index.html`**, localize a linha do avatar (por volta da linha 80):

```html
<div class="profile-avatar-wrapper">
  <img class="profile-avatar" src="https://api.dicebear.com/7.x/bottts/svg?seed=Jonas" alt="Foto de perfil de Jonas" />
</div>
```

Basta alterar o `src` para a sua foto:
- Colocando uma foto dentro da pasta `src/` (ex: `src="./src/sua-foto.jpg"`), **ou**
- Colocando um link direto da imagem na internet (ex: a foto do seu GitHub ou LinkedIn).
